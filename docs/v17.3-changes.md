# GroundedOps v17.3: what changed since v17.2

**Branch:** `experimental/v17.3`, cut on 2026-10-30 from `experimental/v17.2-confluence`.

**Compared with:** v17.2 as last published on GitHub, `origin/experimental/v17.2-confluence` at `5419625` (27 Oct 2026).

**Size:** 115 files changed, 2,218 lines added and 11,953 removed. Most of the removals are the Docker stack.

**Office tooling:** the office's own branch, `experimental/agent-org-phase1` (`tools/`, `ops/`, the agent definitions), is not part of this release and stays separate, as `ops/README.md` requires.

**Not pushed.** Nothing in this release is on GitHub yet.

## Answers

- **Price questions use the documents first.** The bot now searches before deciding. If a passage prices what was asked, the bot answers from it; otherwise it gives the console's fixed sales message. This covers the Repair Information pages' Level 3 repair prices and any uploaded price list. A bare "how much is the NV9" still gets the sales message unless a price list comes up, so a repair price is never quoted as the unit price. The settings page already promised this; before, price questions were never searched.
- **A question naming two products** is searched and answered for both (D-20261019-17). Each product is also searched on its own, which finds pages the joint search missed. A page shared by both products gets a comparison slot only on its score. The chat's own product is no longer added to a one-product comparison.
- **A part of the selected system typed in its chat keeps the chat's scope.** For example, "the SMART Coin System" asked in a CashGenic chat (C20261022c-08). Before, it moved the search to the part's own manuals and refused. Now the chat's product stays in scope and the part's manuals are searched as well. On that branch's 46 cases it measured 86.2% → 91.7%.
- **Variants and family names scope correctly** (D-20261025-11). A product named by its qualifier or short form, or by a family alias that several products share, now goes to the right product.
- **Table read-outs:**
  - count tables whose count columns sit under a non-blank header are read out;
  - a short row under an action column names its group's merged action;
  - read-outs survive the passage cap;
  - new rules for a heading tie and for a vague flash-code question.
- **"Search more thoroughly"** in the widget re-asks a refused question at the deep level (D-20261026-93).

## Documents and search

- **Confluence pages are sorted by kind** (D-20261024-10). The sync stores each page's kind from its title and folder. Release notes and certificates go on the second shelf; change notices stay with the manuals. A backup of the kinds file is kept. The ICU Certificate Management folder counts as API pages, not certificates.
- **Confluence review mode** (D-20261026-02): a write-back to a page that differs from another only in letter case indexes only the approved version.
- **Component suggestions in Documents.** When a product's manuals name another product often enough, a card suggests also searching that product's manuals in its chats (`catalog.scope_links`, `GET /admin/scope_suggestions`). On a data copy it measured 76.5% → 79.8% (NV4000 74.9% → 80.1%). Still waiting for your yes: filing the NV200S manuals under NV4000 on live. That is one click on the NV4000 card.
- **The spec index re-reads only a new or changed PDF.** It used to rebuild every PDF whenever one changed (a cold build took 151 s). The old cache format is converted, so the upgrade itself doesn't trigger a full rebuild.
- **`tools/backfill_figure_text`** adds or removes the picture-label chunks without a full rebuild (D-20261022-15).

## Security

- **The admin IP allowlist** parses addresses and CIDR ranges instead of matching text prefixes (D-20261029-04). `ADMIN_ALLOWED_IPS` takes either.
- **`/query`:**
  - the question length is capped;
  - a wildcard widget origin logs a warning;
  - the widget key and quota limits are pinned (D-20261030-03).
- **A tunnelled staging host** listens on 127.0.0.1 unless started with `-Lan` (D-20261030-01).
- **SECURITY.md** has been added, with private vulnerability reporting.

## Widget and console

- **WCAG contrast** (D-20261026-01):
  - grey text, the wait timer, field borders, the scope bar and the header letter pass;
  - a light ring keeps the launcher visible on dark pages;
  - the console's default accent passes with white text, and the console warns when a chosen accent doesn't.

## Removed and housekeeping

- **The Docker stack**, its Dockerfile, its test and every setup-guide mention of it (D-20261025-01). The widget-export message now points at `src/.env`.
- **Office files** that a merge had brought into the product branch were taken back out (D-20261026-03).
- **New test-rebuild settings:** `EMBED_BATCH` and `LEGACY_SOURCE_DIR`.
- **PENDING.md:** 30 product-owner plan updates.

## Restart needed

None of this reaches the live app until the backend restarts. It runs without auto-reload.
