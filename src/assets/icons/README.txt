GroundedOps custom icons
========================

Drop PNG (or SVG) files here to replace the built-in Material icons on the
left rail. Missing files automatically fall back to the built-in icons, so
you can add them one at a time.

Recommended: square, transparent background, ~48x48px or larger.

Filenames (exact, lowercase):
  toggle.png        expand / collapse the rail
  key.png           DeepSeek key & settings
  folder.png        Documents
  new.png           New chat
  reset.png         Reset knowledge base
  theme_dark.png    shown while in LIGHT mode (click -> go dark)
  theme_light.png   shown while in DARK mode  (click -> go light)

For the app logo (top-left), place a file at:
  src/assets/logo.png     (or logo.svg)
Your logo already contains the wordmark, so the text title is hidden when
this file is present.
