GroundedOps widget

A demo host page. The chat launcher sits in the bottom-right corner. Point it at a running backend, then ask a question about your ingested docs.

Connect to your backend

The backend must run in a mode it can actually answer in (local Ollama, or Online with a key set server-side), and must allow this page's origin via CORS — see the shipped CORS snippet.

Sample doc content

This block just stands in for a real documentation or product page so you can see the widget in context. In production you paste one <script> tag before </body> and the launcher appears on every page it's included on.

  src="https://your-cdn/groundedops-widget.js"
