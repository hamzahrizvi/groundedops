Widget test harness

Reproduces what the WordPress plugin does, so the widget can be exercised as a guest and as a signed-in member before WordPress is involved. The launcher appears bottom-right.

Backend

Use the tunnel hostname to test the real path, or http://127.0.0.1:8000 to test locally.

Identity

Generate one in the app folder with python mint_token.py. WordPress mints these automatically; this stands in for it.

What to verify

  1. As guest, ask something covered by the FAQ. You should get the curated answer, or a "these FAQs match your query" list.
  2. As guest, ask something NOT in the FAQ (e.g. "what are the dimensions?"). You must get the sign-in prompt and never a generated answer. This is the whole security model: no LLM call is reachable without an account.
  3. Open the gear icon. Guest should show FAQ lookups remaining and the sign-in note; member should show credits and the per-answer costs.
  4. As member, ask a documentation question. Expect a generated answer with sources, page numbers, and a working Download source link.
  5. Watch credits fall in the gear panel. A curated FAQ answer should cost nothing; a generated answer costs 1.
  6. Reload the page mid-conversation. You should be offered Continue or Start new.
  7. Click Start over, then reopen the gear. The guest allowance must NOT reset - the visitor id is deliberately separate from the chat session.
  8. Exhaust the guest allowance (set QUOTA_ANON_FAQ=3 and restart) and confirm the limit message appears rather than an error.
